# Data handling policy

- Keep the Kaggle download outside version control under `data/competition/`.
- Do not upload tasks, snapshots, graphs, embeddings, wheels, test patches, reference patches or private evaluator artifacts to this repository.
- Use public development examples only as allowed by the active competition rules.
- Keep training and prompt selection separate from hidden evaluation. Do not use leaderboard probing as a substitute for a validation set.
- Before publishing a paper or notebook, inspect outputs for task text, diffs, filenames that expose hidden information, credentials and model artifacts with incompatible terms.
- Do not assume that Apache-2.0 for project code grants rights to model weights or competition data.
